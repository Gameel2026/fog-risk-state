# fog-risk-state

Levodopa OFF-state detection from freeze-free walking in people with freezing of gait, using a single lower-back accelerometer.

This repository holds the analysis plan, code and results of the study.
The plan in `PLAN.md` was committed before any medication-state result was computed.
Later changes, if any, will appear as dated amendment files.

## Contents
- `PLAN.md` — pre-specified analysis plan.
- `preanalysis_data_checks.py` — data checks run before the plan (units, Valid/Task flags, freeze-free window counts). It computes no medication-state result.

## Data
The study uses the public FoG detection contest data (Salomon et al., Nat. Commun. 2024; Zenodo doi:10.5281/zenodo.12565292).
The data are not redistributed here.
